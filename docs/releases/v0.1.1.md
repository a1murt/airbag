**Undo for AI coding agents.** Airbag snapshots your project before each shell command Claude Code, Codex, Cursor,
Gemini CLI or GitHub Copilot CLI runs that can change files, so a deleted folder, a `git reset --hard` or a wiped
`.env` is one click back.

### Install or upgrade

```bash
brew install --cask a1murt/airbag/airbag     # or: brew upgrade --cask airbag
```

or download `Airbag-0.1.1.dmg` below, drag Airbag to Applications and open it. The build is not notarized yet: on
first launch macOS 15 and later ask once in System Settings → Privacy & Security → Open Anyway; on macOS 14,
right-click → Open. Homebrew installs skip that prompt. `brew upgrade` may say that airbag's signer changed and macOS
may prompt at next launch: the build is ad-hoc signed, and the cask has already removed the quarantine flag, so no
prompt appears.

### New

- **Undo in the menu bar.** The popover lists recent agent commands with what each one changed; Undo brings those
  files back, and the result can be undone too. Restore to an earlier moment is a separate, confirmed action.
- **Reworked screens:** main window and Timeline, Restore, onboarding, a Settings window, Radar and Guard.
- **Notifications you can act on:** allow a waiting command once, stop servers an ended session left running.
- **Stop protecting a folder** from Settings: its snapshots are removed and commands there no longer wait for a
  snapshot; Guard's blocks still apply there.

### Fixed

- The first file an agent wrote into a new, empty folder needed approval (or was refused under bypass permissions)
  because there was nothing to snapshot. An empty folder now needs no snapshot when Airbag saw all of it and found no
  files, and it is the only protected folder the command touches: not when the agent was started in another folder,
  or works in a worktree whose main checkout is protected too.
- A risky command that also needs a snapshot ran under **Record and Keep Going** when the snapshot failed. It now waits
  for you, like any command that needs one (`rm`, `mv`, `git reset --hard`, `git clean`…) and didn't get it, unless
  Airbag is paused.
- Turning a rule off in Guard could also lift a hard block. Blocks now stay.
- `dropdb`, `dropuser` and `mysqladmin drop` were not flagged, locally or over `ssh`. They now ask like other database
  drops.
- Shell commands that switch Airbag off were only recorded where risky commands are recorded instead of asked (Claude
  Code under bypass permissions, Codex, Gemini CLI), and some were not caught at all. Editing, moving or removing an
  agent's user-level hook files or a folder that holds them (Copilot CLI's included), `airbag hooks uninstall`,
  `airbag hooks install --command`/`--home` and `brew uninstall` of Airbag now wait for you unless Airbag is paused.
  Guard reads command text: an agent's own file-edit tools and project-level settings are not covered.

Hook overhead on an Apple M4: about 13 ms for a read-only command, 15–26 ms for one that changes files, depending on
project size (500 to 5,000 files) ([method](https://github.com/a1murt/airbag/blob/main/docs/BENCHMARKS.md)).
