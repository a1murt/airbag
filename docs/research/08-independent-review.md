# 08 — Independent review (2026-10-18)

Four independent reviewers (snapshot engine, hooks and installer, radar and IPC, app) read the code without the
author's conclusions and reproduced each finding with throwaway probes. All findings were fixed; regressions live in
`Tests/AirbagCoreTests/ReviewRegressionTests.swift`.
Totals: 5 blockers, 19 major, 22 minor — all resolved.


| Area | Severity | Finding | Resolution |
|---|---|---|---|
| snapshot-restore | blocker | NFC/NFD path forms collapse in Swift dictionaries but stay separate in SQLite: restore does nothing, and every snapshot records a phantom change | Paths are NFC everywhere they become keys (walker, manifest reads, scopes); stray non-NFC `current` rows are rewritten. Test: renameBetweenNFCandNFD… |
| snapshot-restore | major | Path-scoped restore follows a symlinked parent and moves a file from outside the root into aside/ | Restore checks that every parent is a real directory before any lstat/rename and makes parents real first. Test: pathRestoreNeverWritesOrMovesThroughASymlinkedParent |
| snapshot-restore | major | Files the walk could not see or read are recorded as deleted (or never recorded), and a later restore to that snapshot moves those files aside | Walker reports unreadable dirs/files and skipped large files; those are never tombstoned; capture errors mark the snapshot incomplete. Test: oversizedUnreadableAndUncapturable… |
| snapshot-restore | major | Retention, app project refresh and Timeline diff recreate a deleted project folder (empty) as a side effect | openLocation opens a missing root's store without creating anything; only restore recreates the folder. Test: openingTheStoreOfADeletedProject… |
| snapshot-restore | major | Myers diff keeps a full copy of V for every edit distance: quadratic memory and time, so the Timeline diff can freeze or crash on whole-file rewrites | Common prefix/suffix trimming, O(D²) trace, exact diff up to D=1500 then a replaced block. Test: diffOfAFullRewriteIsBounded… |
| snapshot-restore | minor | Restoring two hard-linked files: the second one is always reported as a conflict and is not restored | Conflict check ignores ctime (changes when a sibling hard link is replaced). Test: restoringHardLinkedFilesRestoresBoth |
| snapshot-restore | minor | Whole-root restore to an incomplete snapshot overwrites files with older versions that snapshot never observed | Restoring to an incomplete snapshot writes only files it captured, moves nothing aside; the restore window says so. |
| snapshot-restore | minor | Restore is refused whenever less than 1 GiB is free (the forced pre-restore snapshot returns .lowDisk) | Pre/post-restore snapshots ignore the 1 GiB floor (refused only below 100 MB). |
| snapshot-restore | minor | aside/ is never pruned, although the docs say it is covered by retention | prune() removes aside/<restore ULID> folders older than the retention window. |
| snapshot-restore | minor | An object-id collision makes capture unlink an existing stored object | An existing object is never unlinked: EEXIST retries with a new id. |
| snapshot-restore | minor | Prune does not update registry.snapshots, so `airbag log` keeps listing snapshot ids that no longer exist | Retention reconciles registry.snapshots (app and `airbag prune`); `airbag log` hides pruned ids. |
| hooks-installer | blocker | Watchdog replies with the stale initial 'allow' for ask-class and snapshot-required commands, so a destructive command runs with no snapshot and no question | Before the snapshot the slot holds the conservative reply (ask, or the escalated ask for snapshot-required commands); the reply is printed before persistence; the manifest busy timeout is bounded. Test: watchdogWouldAnswerConservatively… |
| hooks-installer | blocker | Dedupe key treats a repeated command in the same Cursor generation (or within 3 s for Copilot/Gemini) as a duplicate route: no snapshot, no event, and the snapshot-required escalation is skipped | Dedupe only on tool_use_id; a real duplicate replays the stored decision and reason. Test: sameCommandTwiceInOneCursorGeneration… |
| hooks-installer | major | Codex 'Allow once' cannot work for commands that also need Codex approval: PreToolUse consumes the token, then the PermissionRequest hook denies the same call | PermissionRequest answers only hard blocks; everything else is left to Codex's own prompt. Test: codexPermissionRequestLeaves… |
| hooks-installer | major | Installing into a symlinked settings file (stow, chezmoi symlink mode, home-manager) replaces the symlink with a regular file at mode 0755; read-only configs are silently overwritten | Installer writes through symlinks to the real file (mode kept) and reports read-only files. Test: installWritesThroughSymlinks… |
| hooks-installer | major | Reinstall/'Repair' moves Airbag's Codex groups to the end of each event array, invalidating Codex trust (keyed by group position) for Airbag and for the user's own hooks; status calls such a config 'outdated' | In-place merge keeps group positions; reinstall is a no-op. Test: reinstallKeepsGroupPositionsForCodexTrust |
| hooks-installer | minor | Non-canonical hooks shapes: a non-object `hooks` makes install a silent no-op reported as 'already installed'; a non-array event value is replaced and the user's handler is lost | Non-object `hooks` or non-list events are refused with an explanation; nothing is overwritten. |
| hooks-installer | minor | User comments are silently dropped on rewrite (Gemini settings.json allows comments), and a UTF-8 BOM makes install fail | BOM tolerated; files with comments are refused instead of silently losing them. |
| hooks-installer | minor | `airbag allow <id>` accepts hard-block (deny) entries, reports success and marks them 'user_allowed', but the command stays blocked | allowOnce refuses hard blocks with an explanation. Test: allowOnceRefusesHardBlocks |
| hooks-installer | minor | Shell-form hook commands (Codex, Cursor, Gemini) quote the binary path only when it contains a space or a single quote | Shell-form paths are quoted unless they contain only [A-Za-z0-9_./+-]. |
| radar-stop-ipc | major | A leftover ~/.claude/sessions file whose pid now belongs to another process turns that process into a 'live agent': it gets protected and its children are attributed to a dead session | Claude session files count only when the pid's executable is Claude Code. Test: staleClaudeSessionFile… |
| radar-stop-ipc | major | Sessions that share one agent process (Codex app-server, Cursor extension host) are merged: every child is attributed to an arbitrary session and the correct CODEX_THREAD_ID is ignored | Live agents are grouped by pid; the env session marker picks among sessions sharing a host, else only the agent is attributed. |
| radar-stop-ipc | major | In group mode, Stop never signals descendants in another process group or session; even Force stop leaves them running | Group stop also signals victims in other process groups; individual stops re-validate identity. Test: stopReachesDescendantsInTheirOwnSession |
| radar-stop-ipc | major | An ended session is never revived by later activity, so servers of an actively used agent are reported as ORPHAN (affects radar link state and orphan prompts) | Any non-end hook event clears ended_at. Test: laterActivityRevivesAnEndedSession |
| radar-stop-ipc | major | Wake socket server drops frames: accepted sockets inherit O_NONBLOCK on Darwin, so recv returns EAGAIN and the connection is closed before the CLI's frame arrives | Accepted sockets are switched to blocking with a receive timeout. Test: wakeSocketDeliversMessages |
| radar-stop-ipc | major | KERN_PROCARGS2 parser skips empty argv elements, so environment strings move into argv: non-allowlisted env values are shown and persisted, and markers are lost | KERN_PROCARGS2 parsed by argc (empty args kept); env decoded only for allowlisted keys. Test: procargsKeepsEmptyArguments… |
| radar-stop-ipc | major | Malformed ~/.claude/sessions/*.json with an out-of-range pid crashes the app on every radar tick (and crashes `airbag ports`) | Session-file pids are range-checked (Int32(exactly:)). |
| radar-stop-ipc | minor | CLI `airbag stop` refuses to stop a user's dev server that has any /usr/bin child (classed 'system'), while the app would stop it | 'system process' protection of a descendant no longer blocks stopping its parent. |
| radar-stop-ipc | minor | Server unlinks the socket unconditionally on start and stop: a second app instance (or its exit) makes the running app deaf | A second server refuses to start when the socket is served; stop() unlinks only its own socket (inode check). |
| radar-stop-ipc | minor | Server binds a silently truncated socket path when it is ≥104 bytes, leaves a stray socket file, and every later start fails with EADDRINUSE | Socket path falls back to the per-user temp dir when too long; the server refuses over-long paths. |
| radar-stop-ipc | minor | capture() returns an empty table on any sysctl failure; persist() then ends every incarnation and every session idle for more than 15 s, permanently (because of the revival bug) | persist() does nothing when the process table read fails. |
| radar-stop-ipc | minor | No orphan grace: a server is orphan on the first tick its session looks dead, and the app notifies immediately (doc requires +20 s and cancel on resume) | The app announces orphans after a 20 s grace. |
| radar-stop-ipc | minor | The whole environment of every candidate process is decoded into Swift strings (including OAuth and messaging tokens), against doc 11 §9 | Only allowlisted environment entries are decoded. |
| radar-stop-ipc | minor | umask(0o177) in WakeSocketServer.start is process-wide; concurrent directory creation on other app threads can get 0600 (unusable) directories | No umask change: the socket is created in Airbag's 0700 directory and chmodded 0600. |
| app | blocker | One non-thread-safe SQLite connection (Registry) is used from the main thread and the `work` queue at the same time: segfaults and 100% CPU hangs | A second registry connection is confined to the work queue; retention opens its own. |
| app | blocker | Hooks are installed with the path of wherever the app was launched from (DMG, App Translocation, Downloads); after eject or a move, every agent hook points at a missing binary | Hook path: installed app copy, else the Homebrew link; installing from a DMG or translocated location is refused; broken hook paths turn the icon to 'degraded'. |
| app | major | Restore window keeps its first request forever: later 'Restore…' clicks show (and run) the old request, or only a 'Close' button | The restore request lives in the model; the window resets its state for every new request. |
| app | major | Restore actions on a card restore TO that card's snapshot, while its file list shows changes INTO it, so deleted files cannot be restored from the card that lists them | Cards offer 'Undo these changes' (restore listed paths to the previous snapshot), 'Restore the version from before this change' and 'Restore project to this moment'. |
| app | major | Card title names the first command attached to a snapshot, so the 'Before `rm -rf …`' restore point is labelled with an older, harmless command | Titles use the newest command; every command pointing at a snapshot is listed under it. |
| app | major | Relaunching during a pause leaves the app paused forever: FSEvents snapshots never resume and 'Paused until <past time>' stays | Pause end is scheduled at launch too; a pause in the past clears itself. |
| app | major | Resume timers from earlier pauses are never cancelled: an old timer 'resumes protection' in the app while the registry (hooks) stays paused | One pause timer, replaced on every pause/resume. |
| app | minor | Radar cadence never slows down after the popover closes (or the main window is closed on the Radar tab) | Radar cadence is recomputed when the popover or the main window closes. |
| app | minor | 'Until tomorrow' pause is a fixed 12 hours | 'Until tomorrow morning' pauses until 08:00 tomorrow. |
| app | minor | Launch-at-login toggle silently flips back when SMAppService needs approval | requiresApproval is shown with a message and opens Login Items settings. |
| app | minor | Accessibility: the menu bar item always reads 'Airbag', and several icon-only controls have no label | The menu bar item describes the state; icon-only controls have labels. |
| app | minor | Raw English error descriptions and a hard-coded ' (worktree)' suffix in the localized UI | Common core errors are localized; '(worktree)' is a localized string. |
