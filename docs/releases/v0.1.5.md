**Undo for AI coding agents.** Airbag snapshots your project before each shell command Claude Code, Codex, Cursor,
Gemini CLI or GitHub Copilot CLI runs that can change files, so a deleted folder, a `git reset --hard` or a wiped
`.env` is one click back.

### Install or upgrade

```bash
brew install --cask a1murt/airbag/airbag     # or: brew upgrade --cask airbag
```

or download `Airbag-0.1.5.dmg` below, drag Airbag to Applications and open it. Releases are not notarized yet (there
is no Apple Developer ID): each one is built and ad-hoc signed from its tag by this repository's public release
workflow. From the DMG, macOS asks once on first launch (macOS 15 and later: System Settings → Privacy & Security →
Open Anyway; macOS 14: right-click → Open). The Homebrew cask checks the SHA-256 of that same build and clears its
quarantine flag, so macOS doesn't ask; `brew upgrade` may say that the signer changed, which is expected for an
ad-hoc signed build.

### Fixed

- A shell command with a brace sequence at the edge of the integer range, such as `{0..1..-9223372036854775808}`,
  crashed Airbag's hook. Claude Code, Codex and Cursor run a command when its hook crashes, so
  `rm -rf ~; echo {0..1..-9223372036854775808}` got past Guard. Such sequences are now expanded safely, and every push
  now feeds 2,000 generated hostile commands to the parser in CI (`Scripts/guard-fuzz.py`), which found 18 crashing
  commands in 200 against 0.1.4 and none against 0.1.5.
- A NUL byte inside a command is dropped before Guard reads it, as bash does with what it reads, so it cannot hide
  `rm -rf ~` from Guard.
