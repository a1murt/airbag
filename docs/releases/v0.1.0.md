**Undo for AI coding agents.** Airbag snapshots your project before every shell command Claude Code, Codex,
Cursor, Gemini CLI or GitHub Copilot CLI runs, so a deleted folder, a `git reset --hard` or a wiped `.env` is one
click back.

### Install

```bash
brew install --cask a1murt/airbag/airbag
```

or download `Airbag-0.1.0.dmg` below, drag Airbag to Applications and open it (first launch: System Settings →
Privacy & Security → Open Anyway on macOS 15+, or right-click → Open on macOS 14).

### In this first release

- **Snapshots** before every agent shell command and after file changes, on APFS clones (milliseconds, almost no
  disk), `.env` and git-ignored files included.
- **Timeline and one-click restore** of a file, a folder or the whole project; restores never delete and are undoable.
- **Guard** blocks the few commands no snapshot can undo and records risky ones without stopping your agent.
- **Radar** shows every dev server with the agent session that started it and stops the orphans.
- **Five agents**, any permission mode including bypass and `--yolo`; **19 interface languages**; no account, no
  telemetry, no network.

Replaying 1,987 real agent commands: 96 % run silently, 4.1 % are flagged as risky, 1 is blocked.
