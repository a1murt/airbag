**Undo for AI coding agents.** Airbag snapshots your project before each shell command Claude Code, Codex, Cursor,
Gemini CLI or GitHub Copilot CLI runs that can change files, so a deleted folder, a `git reset --hard` or a wiped
`.env` is one click back.

### Install or upgrade

```bash
brew install --cask a1murt/airbag/airbag     # or: brew upgrade --cask airbag
```

or download `Airbag-0.1.2.dmg` below, drag Airbag to Applications and open it. The build is not notarized yet: on
first launch macOS 15 and later ask once in System Settings → Privacy & Security → Open Anyway; on macOS 14,
right-click → Open. Homebrew installs skip that prompt. `brew upgrade` may say that airbag's signer changed and macOS
may prompt at next launch: the build is ad-hoc signed, and the cask has already removed the quarantine flag, so no
prompt appears.

### New

- **A new icon.** The shield is drawn as an airbag: an inflated, stitched cushion with the undo arrow on it. Small
  sizes have their own, bolder drawings.

### Fixed

- A command run from one folder that deletes or resets files in another protected folder, such as `rm ../notes.txt`
  from a nested repository inside the folder the agent was started in, or a path in a worktree's main checkout, now
  takes a snapshot of that folder first, and waits for you if it can't. Before, only the session's folder was
  snapshotted.
