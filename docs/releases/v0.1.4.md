**Undo for AI coding agents.** Airbag snapshots your project before each shell command Claude Code, Codex, Cursor,
Gemini CLI or GitHub Copilot CLI runs that can change files, so a deleted folder, a `git reset --hard` or a wiped
`.env` is one click back.

### Install or upgrade

```bash
brew install --cask a1murt/airbag/airbag
```

Already installed: `brew upgrade --cask airbag`.

Or download `Airbag-0.1.4.dmg` below, drag Airbag to Applications and open it. The build is not notarized yet: on
first launch macOS 15 and later ask once in System Settings → Privacy & Security → Open Anyway; on macOS 14,
right-click → Open. Homebrew installs skip that prompt. `brew upgrade` may say that airbag's signer changed and macOS
may prompt at next launch: the build is ad-hoc signed, and the cask has already removed the quarantine flag, so no
prompt appears.

### New

- **`airbag undo`** in the terminal: puts back what the newest change in a project did, or a given one, with `--list`
  and `--dry-run`. It is the menu bar's Undo, and it can be undone the same way.
- **A plugin for Claude Code.** In Claude Code, `/plugin install airbag --marketplace a1murt/airbag` (before
  2.1.275: `/plugin marketplace add a1murt/airbag`, then `/plugin install airbag@airbag`). It connects Claude Code to
  Airbag without editing `settings.json` and adds `/airbag:undo`, `/airbag:changes` and `/airbag:status`. The app
  (above) still takes the snapshots; the plugin needs Airbag 0.1.4 or later, and steps aside where Airbag has already
  connected Claude Code itself.
- **Guard speaks your language.** Each flagged command is explained in the interface language, in all 19.
- **Agent worktrees are protected on their own.** A worktree under `.claude/worktrees` or `.codex/worktrees` gets its
  own snapshots, taken before a command deletes, moves or overwrites anything in it.
- **Snapshots of folders that are long gone are removed.** 30 days after a folder disappears (3 days for temporary
  folders and agent worktrees) its snapshots are deleted, unless one is pinned. `airbag cleanup` does it on request.

### Fixed

- Deleting an agent worktree ran as "restorable" although no snapshot held its files.
- Deleting a file over 100 MB, which snapshots skip, ran as "restorable" and the file was lost. Such a command now
  waits for you.
- Guard let a home-folder delete through when the command was piped into a shell (`echo … | sh`), or hidden in
  `env -S`, awk's `system()`, a git alias, `core.sshCommand` or a vim `:!`. They are read like `sh -c` now.
- `airbag hooks uninstall --all --help` removed every agent's hooks, and a misspelled option was ignored
  (`airbag prune --dryrun` pruned for real). `--help` and unknown options never run a command.
- Claude Code's own temporary folder was snapshotted as a project and collected gigabytes. It is never a project.
- Dragging Airbag.app to the Trash while Gemini CLI or Copilot CLI were connected left both refusing every shell
  command. Their hooks now step aside when the app is gone.
- Radar listed Colima's virtual machine as servers a session left running, and offered to stop it.
- Reading Airbag's own database with `sqlite3` was blocked as if it were a write.
- An agent could delete snapshots with `airbag prune`. It is asked first, like anything else that weakens Airbag.
- Airbag's own reading commands (`airbag log`, `guard`, `undo --list`, `hooks status`…) took a snapshot of the
  project. They no longer do.
