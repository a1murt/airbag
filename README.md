# Airbag

Airbag is a free, native macOS menu bar utility that acts as a safety net for local AI coding agents
(Claude Code, Codex, Cursor, Gemini CLI): project snapshots before every agent shell command,
a timeline with one-click rollback, a circuit breaker for destructive commands, and a radar of
dev servers and ports attributed to the agent session that started them.

Status: pre-alpha, under active construction. See `docs/PLAN.md`.
