**Undo for AI coding agents.** Airbag snapshots your project before each shell command Claude Code, Codex, Cursor,
Gemini CLI or GitHub Copilot CLI runs that can change files, so a deleted folder, a `git reset --hard` or a wiped
`.env` is one click back.

### Install or upgrade

```bash
brew install --cask a1murt/airbag/airbag     # or: brew upgrade --cask airbag
```

or download `Airbag-0.1.3.dmg` below, drag Airbag to Applications and open it. The build is not notarized yet: on
first launch macOS 15 and later ask once in System Settings → Privacy & Security → Open Anyway; on macOS 14,
right-click → Open. Homebrew installs skip that prompt. `brew upgrade` may say that airbag's signer changed and macOS
may prompt at next launch: the build is ad-hoc signed, and the cask has already removed the quarantine flag, so no
prompt appears.

### Fixed

- Airbag could quit unexpectedly when it watched a few dozen projects or more. Watching them asked for an open file
  per folder on the way to every project, more than a Mac app gets by default, and the failed attempt closed a file
  the app still used. Until then, changes made outside agent commands in those projects were not snapshotted either.
  Watching no longer needs a file per folder, and the app allows itself more open files.
